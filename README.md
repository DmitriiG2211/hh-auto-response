# HH автоотклики

Локальный userscript для последовательных откликов из текущей поисковой выдачи HeadHunter. Скрипт работает на `hh.ru`, `hh.kz` и `hh.uz`. Он обрабатывает вакансии по одной, считает подтверждённые отправки и продолжает работу после перехода между страницами выдачи.

Проект не связан с HeadHunter. Интерфейс сайта может измениться; перед использованием проверьте работу на небольшом лимите и подходящей поисковой выдаче.

## Что потребуется

- Аккаунт HeadHunter, в который вы уже вошли в браузере.
- Яндекс Браузер, Chrome, Edge или другой браузер, поддерживающий Violentmonkey либо локальные расширения Chromium.
- Для локальной страницы установки и ярлыка на Windows: [Node.js](https://nodejs.org/). Для установки userscript из файла Node.js не нужен.

## Установка через Violentmonkey

Этот вариант подходит для Яндекс Браузера, если Violentmonkey уже установлен.

1. Скачайте репозиторий: на GitHub нажмите **Code → Download ZIP**, затем распакуйте архив в постоянную папку. При последующих обновлениях содержимое этой папки можно заменить новой версией.
2. Откройте Violentmonkey и создайте новый скрипт.
3. Замените содержимое редактора текстом из файла [`hh-auto-response.user.js`](hh-auto-response.user.js), сохраните скрипт и убедитесь, что он включён.
4. Откройте страницу поиска вакансий HeadHunter и обновите её. Справа внизу появится панель **HH автоотклики**.

Если Violentmonkey уже содержит старую версию, откройте её в редакторе, замените код целиком и сохраните. Не создавайте вторую активную копию: два экземпляра могут одновременно нажимать кнопки на сайте.

### Установка через локальную страницу

В папке проекта на Windows запустите [`Запустить HH Auto.cmd`](Запустить%20HH%20Auto.cmd). Если у вас уже есть личный ярлык для этой папки, можно открыть его. Скрипт запустит локальный сервер и откроет `http://127.0.0.1:8787`. Нажмите **Открыть userscript** и подтвердите установку или обновление в Violentmonkey.

Если браузер показывает только текст файла и не предлагает установку, используйте установку через редактор Violentmonkey, описанную выше. Локальный сервер доступен только с вашего компьютера; он раздаёт файлы проекта и сам не отправляет отклики.

## Установка как локальное расширение

Используйте этот вариант, если не хотите применять Violentmonkey.

1. Скачайте и распакуйте репозиторий в постоянную папку. В её корне должны лежать `manifest.json` и `hh-auto-response.user.js`.
2. Откройте страницу расширений браузера. В Chrome это `chrome://extensions`, в Edge — `edge://extensions`; в Яндекс Браузере откройте **Меню → Дополнения** и найдите управление расширениями.
3. Включите **Режим разработчика** и выберите **Загрузить распакованное расширение**.
4. Укажите папку из шага 1. Включите расширение, если браузер его выключил.
5. Обновите вкладку с поисковой выдачей HeadHunter.

После замены файлов расширения на новую версию нажмите кнопку перезагрузки именно карточки **HH: безопасные автоотклики из поиска** на странице расширений, затем обновите вкладку HH. Не устанавливайте одновременно расширение и userscript в Violentmonkey: выберите один способ.

## Как пользоваться

1. Войдите в HeadHunter и откройте **поисковую выдачу вакансий**.
2. Настройте запрос, регион, опыт, зарплату и другие фильтры. Скрипт работает только с вакансиями, показанными в этой выдаче.
3. В панели задайте лимит успешных откликов, минимальную и максимальную паузу. При необходимости впишите текст сопроводительного письма.
4. Оставьте включённым флажок **Пропускать обязательные письма, вопросы и сложные формы**, если хотите обходить вакансии, требующие ручного заполнения.
5. Нажмите **Запустить** и подтвердите отправку откликов. Для первой проверки установите небольшой лимит, например 1–3.
6. Следите за счётчиками и сообщением в панели. **Остановить** прерывает работу; **Сброс** очищает сохранённый прогресс и статистику.

Лимит относится к **подтверждённым** откликам. Число попыток может быть больше лимита: вакансии со сложной анкетой пропускаются, а часть откликов может завершиться ошибкой. Минимальная пауза — 3 секунды; исходная настройка — случайные 7–12 секунд. Скрипт дополнительно ограничивает общее число попыток.

## Поведение на сложных формах

- Всплывающую форму с обязательным письмом, вопросами работодателя, тестом или неизвестными полями скрипт пропускает. Если закрыть её обычным способом не удалось, перезагружает выдачу и продолжает с сохранённого места.
- Если отклик открыл отдельную страницу с вопросами, скрипт запоминает вакансию, возвращается к прежней выдаче и продолжает со следующей. Для этого новая версия должна быть установлена и на странице `/applicant/vacancy_response`.
- Внешние анкеты и нестандартные ссылки пропускаются.
- При снятом флажке пропуска скрипт останавливается на сложной форме для ручного заполнения.
- Капча, ограничение запросов, необходимость входа и три ошибки подряд останавливают работу.

Прогресс хранится в `localStorage` браузера и может восстановиться после перезагрузки или перехода на другую страницу выдачи в течение 30 минут. При переходе на совершенно другой поисковый запрос начните новую сессию кнопкой **Сброс**.

## Если скрипт остановился

1. Прочитайте последнюю строку панели. Если открыта страница с вопросами, проверьте, что установлена версия `2.2.0` или новее и включён флажок пропуска сложных форм.
2. Обновите userscript в Violentmonkey либо перезагрузите локальное расширение, затем обновите вкладку HH.
3. Вернитесь к поисковой выдаче, нажмите **Сброс** и запустите небольшой тест. Если сайт показывает капчу или ограничение, завершите проверку вручную и подождите, прежде чем снова запускать скрипт.

## Состав проекта и проверка

| Файл | Назначение |
| --- | --- |
| [`hh-auto-response.user.js`](hh-auto-response.user.js) | Основной скрипт для Violentmonkey и локального расширения |
| [`manifest.json`](manifest.json) | Описание локального расширения Chromium |
| [`server.mjs`](server.mjs), [`index.html`](index.html) | Локальная страница установки на `127.0.0.1:8787` |
| [`Запустить HH Auto.cmd`](Запустить%20HH%20Auto.cmd) | Запуск локальной страницы на Windows |
| [`test-harness.html`](test-harness.html) | Локальная демонстрационная страница без отправки данных в HH |

Скрипт не содержит сетевых запросов к сторонним сервисам, не читает cookie и не устанавливает дополнительное ПО. Расширение не запрашивает разрешений сверх доступа к указанным страницам HeadHunter. Перед установкой можно открыть исходный код и проверить его самостоятельно.

Для проверки синтаксиса при установленном Node.js выполните `node --check hh-auto-response.user.js`, а для локального запуска — `node server.mjs`. Демонстрация доступна по адресу `http://127.0.0.1:8787/search/vacancy-test`.
